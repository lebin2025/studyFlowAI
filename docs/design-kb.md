## 3. StudyFlow AI 的设计定位

### 产品分类

- 类型：**AI-native learning product + SaaS / Tool**
- 首要目标：**帮助用户完成今天的学习任务**
- 次要目标：建立信任、表达品牌、产生平静的情绪
- 核心任务：输入目标 → 生成计划 → 编辑/保存 → 完成任务 → 查看统计 → AI 调整

### 主艺术方向

本次整站升级采用**一个主方向**：

- **Editorial Loom / 学习织机**——瑞士编辑式构图、纸面与墨线、单一朱红信号色、编织路径图与超大衬线排版。
- **Quiet Precision** 负责数据、操作与状态；**Human Warmth** 负责文案、节奏与留白。
- 不使用明暗主题切换、玻璃拟态、渐变按钮或三列卡片网格作为默认结构。

页面不是“深色营销页 + 浅色工作台”两套皮肤，而是同一张纸上的不同版面：目标、时间与行动被织成可以每天走通的路径。

辅助：

- **AI-native Interface**：输入、生成中、可编辑结果、失败重试都要清楚
- **Quiet Precision**：标题、排版、间距与状态要精确

### 视觉母题

**成长轨迹 / 小步前进**：计划阶段、每日任务、进度、连续学习天数都围绕“今天向前一小步”组织，而不是装饰性的星星或科技光效。

### 情绪关键词

平静、可信、温和、专注、有掌控感。

### 现有设计系统

保留并细化现有 `src/assets/styles/tokens.css`：

- 暖白底、低饱和薰衣草/薄荷/蜜桃强调色
- 圆润但不过度胶囊化
- 轻阴影、细边框、克制动效
- 中文优先字体栈
- 现有组件与交互不无理由重写

## 4. 每次改页面的固定流程

1. **理解**：页面服务哪个用户任务？首屏必须传达什么？
2. **查上下文**：读现有路由、组件、tokens、API、状态处理。
3. **定方向**：一个主风格 + 最多两个辅助；写一句视觉母题。
4. **定系统**：网格、字号层级、颜色语义、间距、圆角、阴影、动效时长。
5. **先结构后装饰**：内容、层级、状态、响应式先成立，再加材质与动效。
6. **实现**：优先改 tokens 和现有组件，不复制一套新体系。
7. **验证**：build、相关测试、真实浏览器截图、键盘/移动端/减少动态。
8. **批评**：按 `13` 的顺序从产品价值、主焦点、构图、层级往下查。
9. **交付**：说明改了什么、实际跑了什么、没验证什么。

## 5. 页面验收清单

### 视觉

- [ ] 首屏只有一个明确主焦点
- [ ] 产品价值在不滚动时能看懂
- [ ] 标题/正文/注释层级清楚，正文行长可读
- [ ] 颜色有语义，强调色没有平均分配
- [ ] 材质与光影逻辑一致，没有到处发光/玻璃化
- [ ] 空状态、加载、错误、成功状态完整
- [ ] 移动端是重新排版，不是桌面等比缩小

### 功能

- [ ] 所有看起来可点击的控件都有行为
- [ ] 表单校验、错误说明、焦点状态可用
- [ ] AI 的生成中/成功/失败/重试状态清楚
- [ ] 真实 API 与演示数据不混淆
- [ ] 登录、权限、数据隔离未被破坏

### 工程

- [ ] `npm run build` 通过
- [ ] 相关测试通过
- [ ] 无控制台错误、无横向溢出
- [ ] 键盘可完成核心操作
- [ ] 支持 `prefers-reduced-motion`
- [ ] 没有把密钥放进前端

## 6. 本项目明确拒绝的模式

- 通用 SaaS 三列功能卡片模板
- 整站玻璃拟态、所有元素发光/渐变
- 无意义的 3D、粒子、霓虹“未来感”
- 超大标题但没有编辑节奏
- 低对比灰字承载关键说明
- 滚动劫持、冗长开场动画、装饰性光标
- 复制 Apple 的具体页面、图片、Logo 或版式
- 把文化传统当装饰滤镜（水墨背景 + 红印章 ≠ 中国美学）
- 用假数据、假加载、假 AI 结果制造“高级感”

## 7. 设计决策的交付格式

做较大页面改动时，先在回复中简短说明：

1. 页面/功能目标
2. 主风格与辅助风格
3. 视觉母题
4. 关键视觉系统（网格、字体、颜色、材质、动效）
5. 技术选型与成本
6. 验收标准
7. 实际验证结果

不需要把整本知识库复述给用户；引用与决策相关的原则即可。

# StudyFlow ambience audio

The four MP3 files in this directory were supplied by the StudyFlow project
owner for use inside this application:

- `forest.mp3`
- `moon.mp3`
- `snow.mp3`
- `sunset.mp3`

They replace the earlier Web Audio noise synthesis. The application only
loads a file after the user chooses it; it does not autoplay.

Redistribution outside this project should be checked with the project owner.
